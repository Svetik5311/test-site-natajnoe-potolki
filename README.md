# Потолок&Свет

Сайт бренда натяжных потолков в Набережных Челнах. Учебный проект (урок 17).

## Структура

- `brand/` - паспорт бренда (brand.md) и логотип (logo.svg)
- `site/` - первая версия сайта: светлый классический лендинг
- `site-v2/` - вторая версия в стиле Dribbble: тёмная тема, градиенты, стеклянные карточки

## Запуск локально

```bash
cd site        # или site-v2
npm run dev    # откроется http://localhost:7100/
```

Каждая версия автономна: нужен только Node.js, зависимостей нет.
